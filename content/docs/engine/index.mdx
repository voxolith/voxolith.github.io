`@voxolith/engine` sits between the [renderer](/docs/renderer/) and an app. It holds the
**entity**, the unit a world is built from (a voxel model with an anchor and named colour roles),
and everything a host does with one: palette it, orient it, place it, stream it, draw it by
reference, move it, animate it. It also holds the generator *contract*, so a host can build a
model from a seed at runtime.

The engine consumes baked models and never authors them. The authoring toolkit (dense volumes,
rasterisers, noise, branch growth, canopy carving, rock masses) and the headless preview renderer
are [`@voxolith/gen-kit`](/docs/generators/gen-kit/), beside the generators.

## Entry points

| import | contents |
|---|---|
| `@voxolith/engine` | entity and generator contracts, registry, share codes, palette allocation, orientation, placement, chunked worlds, instance layers, brick stamping. Runtime-safe: no DOM, no GPU, no filesystem |
| `@voxolith/engine/vox` | MagicaVoxel import and export of entities |
| `@voxolith/engine/worker` | an off-thread generator pool, with an optional IndexedDB model cache |
| `@voxolith/engine/animation` | rigs and clips: play, pose, bake posed models at any heading, wound and sever, pose cache, crowds. Headless and pure |
| `@voxolith/engine/atmosphere` | time of day and weather as configuration, translated into renderer settings. Headless and optional |
| `@voxolith/engine/input` | pointers, keys, wheel, pointer lock, gamepad, gestures, actions, on-screen touch controls, orbit and look cameras. DOM only |

The subpaths are split by realm: the barrel runs anywhere (a worker, a bun script, a test), input
needs a DOM, and the worker entry has a main-thread half and a worker half.

```ts
import { PaletteAllocator, blitModel } from "@voxolith/engine";
import { entityFromVox } from "@voxolith/engine/vox";

const tree = entityFromVox(await (await fetch("oak.vox")).arrayBuffer(), { kind: "tree" });
const palette = new PaletteAllocator();
const { base } = palette.allocateFor(tree);
blitModel(world, tree.model, { x: 64, y: 0, z: 64 }, base);
renderer.updatePalette(palette.buildPalette());
```
