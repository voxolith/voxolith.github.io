Voxolith is an open-source **WebGPU voxel engine** for the browser. It draws voxel worlds by
raymarching them on the GPU, with no meshes: every pixel walks a brick index until it hits a voxel,
then shades it with soft shadows, ambient occlusion, point lights, fog and water. On top of the
renderer sit an engine layer (entities, placement, streaming, input, animation, atmosphere) and a
set of procedural generators that build trees, rocks, buildings, creatures and terrain from a seed.

Everything is TypeScript and WGSL, MIT licensed, and developed in the open at
[github.com/voxolith](https://github.com/voxolith).

## The layers

| layer | package | does |
|---|---|---|
| Renderer | [`@voxolith/renderer`](/docs/renderer/) | draws voxels: storage, instances, lighting, atmosphere, cameras, `.vox` and `.mca` I/O |
| Engine | [`@voxolith/engine`](/docs/engine/) | entities and colour roles, the generator contract, placement, streaming, input, animation, weather as configuration |
| Generators | [`@voxolith/gen-*`](/docs/generators/) | bake models: trees, bushes, grass, rocks, buildings, rigged creatures, terrain |
| Apps | [viewer, editor, examples, demolition-shot](/docs/examples/) | built on the three above |

Each layer knows only the one below it. The renderer knows nothing about weather or entities; the
engine never authors a model; generators never touch the GPU.

## Requirements

Voxolith is **WebGPU only**, with no WebGL fallback. It needs a browser with `navigator.gpu` in a
secure context (HTTPS or `localhost`):

- Chrome or Edge, current versions, on desktop and Android
- Safari 26 or later
- Firefox with WebGPU enabled

If a page stays blank or is slow, see [troubleshooting](/docs/troubleshooting/).
