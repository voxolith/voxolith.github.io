In this step you create the project and draw the first frame: an empty world under a morning sky.
It is not much to look at, but it proves the whole chain works: bun, Vite, TypeScript, WebGPU
and the renderer.

## The workspace

The Voxolith packages are not on npm yet, so the game lives in a bun workspace next to checkouts
of the three library repos (see [Installation](/docs/getting-started/installation/) for why).

```sh
mkdir voxolith && cd voxolith
git clone https://github.com/voxolith/renderer
git clone https://github.com/voxolith/engine
git clone https://github.com/voxolith/generators
mkdir -p rat-hunt/src
```

## The app

The game uses the renderer, the engine and four generators. Declare them all now, so you only
install once:

```json title="rat-hunt/package.json"
{
  "name": "rat-hunt",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc --noEmit && vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "@voxolith/renderer": "workspace:*",
    "@voxolith/engine": "workspace:*",
    "@voxolith/gen-terrain": "workspace:*",
    "@voxolith/gen-tree": "workspace:*",
    "@voxolith/gen-building": "workspace:*",
    "@voxolith/gen-creature": "workspace:*"
  },
  "devDependencies": {
    "@vitejs/plugin-basic-ssl": "^2.3.0",
    "@webgpu/types": "^0.1.74",
    "typescript": "^7.0.2",
    "vite": "^8.3.0"

```

```ts title="rat-hunt/vite.config.ts"
import { defineConfig } from "vite";
import basicSsl from "@vitejs/plugin-basic-ssl";

export default defineConfig({
  // GitHub Pages serves the game under /<repo>/; step 7 sets BASE_PATH.
  base: process.env.BASE_PATH ?? "/",
  // WebGPU needs a secure context, also on a phone on the LAN.
  plugins: [basicSsl()],
  server: { host: true },
  // The renderer ships TypeScript with `?raw` shader imports: compile it with the app.
  optimizeDeps: { exclude: ["@voxolith/renderer"] },
});
```

## The first frame

```ts title="rat-hunt/src/main.ts"
// Rat Hunt: catch the giant rats in the valley before night falls.
import {
  createRenderer,
  initGpu,
  makeCamera,
  makeFrameLoop,
  observeResize,
  resizeToDisplay,
  showUnsupportedScreen,
  WebGPUUnsupportedError,
} from "@voxolith/renderer";
import { atmosphereFrame, ATMOSPHERES, timeOfDay } from "@voxolith/engine/atmosphere";
import "./style.css";

const canvas = document.getElementById("scene") as HTMLCanvasElement;

// --- WebGPU -------------------------------------------------------------------
const gpu = await initGpu(canvas).catch((err: unknown) => {
  if (err instanceof WebGPUUnsupportedError) showUnsupportedScreen(err.message, { appName: "Rat Hunt" });
  throw err;
});

// --- an empty world ---------------------------------------------------------------
const SIZE = { x: 384, y: 128, z: 384 };
const renderer = await createRenderer(gpu, { size: SIZE, palette: new Float32Array(256 * 4) });
renderer.setClipBounds([0, 0, 0], [SIZE.x - 1, SIZE.y - 1, SIZE.z - 1]);

const camera = makeCamera({ target: [SIZE.x / 2, 20, SIZE.z / 2], distance: 420, pitchDeg: 30, fovDeg: 45 });
const sky = atmosphereFrame(timeOfDay(0.35), ATMOSPHERES.clear);

// --- the loop ------------------------------------------------------------------------------
const loop = makeFrameLoop({
  render() {
    resizeToDisplay(gpu);
    renderer.render({ ...camera(30), ...sky });
  },
});
observeResize(canvas, loop);
loop.invalidate();
```

What this does:

- **`initGpu(canvas)`** opens WebGPU on the canvas. If the browser cannot, it throws a
  `WebGPUUnsupportedError` and `showUnsupportedScreen` replaces `#app` with an explanation, which
  is far kinder than a blank page.
- **`createRenderer(gpu, { size, palette })`** makes a renderer for a world of 384 × 128 × 384
  voxels. There are no voxels yet (no `data`), and the palette is 256 empty colours.
  `setClipBounds` tells the renderer the whole box is in use, since it cannot infer that from an
  empty world.
- **`makeCamera`** gives a function that turns a yaw (in degrees) into the camera fields a frame
  needs.
- **`timeOfDay(0.35)`** is the lighting for mid-morning: 0 is midnight, 0.25 sunrise, 0.5 noon,
  0.75 sunset. `atmosphereFrame` adds the weather to it, here `ATMOSPHERES.clear`.
- **`makeFrameLoop`** calls `render` when a frame is needed. Nothing moves yet, so it renders
  once (`loop.invalidate()`) and again whenever the canvas is resized (`observeResize`).

## Run it

```sh
bun run --cwd rat-hunt dev
```

Open the `https://localhost:5173` URL that Vite prints and accept the self-signed certificate.
You should see a blue sky fading to a pale horizon, and the HUD saying "loading…". To try it on
a phone, open the `https://192.168...` network URL instead.

If the page says WebGPU is unavailable, see [Troubleshooting](/docs/troubleshooting/).
